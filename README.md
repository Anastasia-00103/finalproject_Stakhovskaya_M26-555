
# ValutaTrade Hub

**ValutaTrade Hub** — консольное приложение на Python для управления виртуальным валютным портфелем, покупки и продажи фиатных и криптовалют, а также отслеживания актуальных обменных курсов.

## 1. Описание проекта

ValutaTrade Hub представляет собой CLI-приложение с отдельным сервисом получения и обновления валютных курсов (Parser Service).

Основная идея проекта — предоставить пользователю возможность работать с виртуальным валютным портфелем без использования реальных денежных средств.

Основные возможности:
- регистрация и авторизация пользователей;
- создание и управление виртуальными кошельками;
- просмотр валютного портфеля и балансов;
- покупка и продажа валют;
- получение актуальных обменных курсов;
- обновление курсов через внешние API;
- хранение истории изменения валютных курсов;
- использование кэширования с ограниченным временем жизни (TTL).

### Основные компоненты

**Core — бизнес-логика**
- `models.py` — модели пользователей, кошельков и портфелей (`User`, `Wallet`, `Portfolio`).
- `exceptions.py` — пользовательские исключения для обработки ошибок.
- `usecases.py` — основные сценарии работы приложения: регистрация, покупка и продажа валют, получение курсов.

**Infra — инфраструктура**
- `settings.py` — настройки приложения, включая пути к файлам и TTL кэша.
- `logging_config.py` — настройка системы логирования.

**Parser Service — сервис получения курсов**
- `config.py` — конфигурация внешних API.
- `api_clients.py` — клиенты для взаимодействия с CoinGecko и ExchangeRate-API.
- `updater.py` — получение и обновление валютных курсов.
- `storage.py` — сохранение курсов и истории изменений.

**Дополнительные компоненты**
- `decorators.py` — декораторы для дополнительной обработки операций.
- `main.py` — точка входа в приложение.
- `data/` — хранение данных приложения в формате JSON.
- `logs/` — хранение журналов операций.
- `tests/` — тесты проекта.

```bash
uv run python -m valutatrade_hub.main
```

## 5. Использование CLI

Приложение предоставляет консольный интерфейс для управления валютным портфелем.

Основные предусмотренные операции:

| Команда | Назначение |
|---|---|
| `register` | Регистрация нового пользователя |
| `login` | Авторизация пользователя |
| `show-portfolio` | Просмотр валютного портфеля |
| `buy` | Покупка валюты |
| `sell` | Продажа валюты |
| `get-rate` | Получение обменного курса |
| `update-rates` | Обновление валютных курсов |
| `show-rates` | Просмотр сохранённых курсов |
| `exit` | Завершение работы |

### Примеры использования

**Регистрация пользователя:**

```bash
register --username Anastasia --password 123456
```

**Авторизация:**

```bash
login --username Anastasia --password 123456
```

**Просмотр портфеля:**

```bash
show-portfolio --base USD
```

**Покупка валюты:**

```bash
buy --currency BTC --amount 0.01
```

**Продажа валюты:**

```bash
sell --currency EUR --amount 100
```

**Получение курса:**

```bash
get-rate --from BTC --to USD
```

**Обновление курсов:**

```bash
update-rates --source coingecko
```

**Просмотр сохранённых курсов:**

```bash
show-rates --currency BTC
```

Приведённые команды демонстрируют предполагаемый формат пользовательских операций; фактический синтаксис определяется реализованным CLI.

## 6. Parser Service

Parser Service отвечает за получение актуальных обменных курсов из внешних источников, обработку полученных данных и их сохранение.

В проекте предусмотрена интеграция со следующими API:

### CoinGecko

- Источник курсов криптовалют.
- Поддерживаемые валюты: BTC, ETH, SOL.
- Используется для получения актуальных рыночных котировок.

### ExchangeRate-API

- Источник курсов фиатных валют.
- Поддерживаемые валюты: EUR, GBP, RUB.
- Для запросов требуется API-ключ.

### Принцип работы Parser Service

1. Пользователь инициирует обновление валютных курсов.
2. Parser Service обращается к соответствующему внешнему API.
3. Полученные данные обрабатываются и приводятся к необходимому формату.
4. Актуальные курсы сохраняются в JSON-хранилище.
5. История обновлений сохраняется отдельно.
6. Core использует сохранённые данные для выполнения операций с валютами.

## 7. Кэширование и TTL

Для уменьшения количества обращений к внешним API и ускорения работы приложения используется механизм кэширования валютных курсов.

Основные файлы:

- `data/rates.json` — хранение актуальных валютных курсов.
- `data/exchange_rates.json` — хранение истории обновлений курсов.

**TTL (Time To Live)** — время, в течение которого сохранённые данные считаются актуальными.

В проекте предусмотрена настройка TTL через `infra/settings.py`.

Значение по умолчанию — 300 секунд (5 минут).

Принцип работы:

1. При запросе курса приложение проверяет наличие сохранённых данных.
2. Проверяется время последнего обновления.
3. Если срок действия кэша не истёк, используются сохранённые курсы.
4. Если TTL истёк, данные считаются устаревшими.
5. Пользователь получает уведомление о необходимости обновления курсов.
6. После выполнения `update-rates` кэш обновляется.

Такой подход позволяет сократить количество внешних запросов и использовать актуальные данные при совершении операций.

## 8. Обработка ошибок и логирование

В проекте предусмотрена обработка ошибок с использованием пользовательских исключений.

Основные типы ошибок:
- недостаточно средств для совершения операции;
- неизвестная валюта;
- ошибка получения данных от внешнего API;
- некорректные входные данные;
- ошибки чтения и записи JSON-файлов.

Логирование позволяет отслеживать действия пользователей, операции с валютами и ошибки приложения.

Журналы операций сохраняются в директории `logs/`.
