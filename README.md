# ValutaTrade Hub

Комплексная платформа для отслеживания и симуляции торговли фиатными и крипто валютами.

## Описание проекта

Проект представляет собой консольное приложение (CLI), которое позволяет пользователям:
- Управлять виртуальным портфелем валют.
- Совершать сделки по покупке и продаже.
- Отслеживать актуальные курсы валют (в перспективе — через сервис парсинга).

## Архитектура

Проект разделен на логические слои:

- **`valutatrade_hub/core/models.py`** — классы предметной области (Пользователь, Кошелек, Портфель, Транзакция).
- **`valutatrade_hub/core/usecases.py`** — бизнес-логика (сценарии использования: регистрация, торговля, просмотр баланса).
- **`valutatrade_hub/core/utils.py`** — вспомогательные функции (работа с JSON, форматирование).
- **`valutatrade_hub/cli/interface.py`** — интерфейс командной строки, парсинг команд и вывод.
- **`data/`** — директория для хранения данных в формате JSON (пользователи, портфели, курсы).
